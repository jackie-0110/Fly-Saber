# FlyArcade frontend

A static, responsive Fly Saber observation workspace built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui. The dark grey workstation layout follows the project handoff and supplied references: a dominant game viewport, right-hand brain inspector, and bottom timeline/readouts.

## Run locally

```bash
cd frontend
npm ci
npm run dev
```

Open the local URL printed by Vite. To check a production build:

```bash
npm run build
npm run preview
```

`npm run lint` checks the frontend with Oxlint.

`npm run format` formats the frontend source with Prettier; `npm run format:check` verifies it.

## Preview behavior

- Game and neural views are original static SVG illustrations, not live data or a recording.
- Fullscreen viewing and the Activity/Details/Next steps inspector tabs work. Playback is disabled until a real session is connected.
- Both future views will be real 3D: Fly Saber with a movable camera, and the neural point cloud with independent orbit controls. The current static images do not rotate.
- No API, WebSocket, model, audio, or connectome download is needed to view the page. Google Fonts enhance typography when available; local font fallbacks keep the UI readable offline.
- No measured neuron counts, firing rates, or scores are fabricated.

The frontend lives in the canonical `frontend/` directory. You can also run it from the repository root with `make frontend`. Vite retains the `/api` and `/ws` proxies to the local server on port 8000; this static preview does not use them yet.

## Illustration sources

`public/previews/fly-saber.svg` is a hand-authored vector illustration. The neural point cloud is a seeded decorative illustration generated by a dependency-free Python script:

```bash
python3 scripts/generate_neural_preview.py
```

That script generates artwork only. Its positions and brightness must never become scientific fixtures, neuron metadata, or activity samples. Future data contracts must follow inspected backend files and [docs/PROTOCOL.md](../docs/PROTOCOL.md).
